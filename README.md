# KRONOCLOS — Website + Interactive Demo

KRONOCLOS เป็นโครงการของ ORIONS CREATIVE CO., LTD. ทำหน้าที่เป็นซอฟต์แวร์ (แพลตฟอร์ม + แอป) ส่วนฮาร์ดแวร์มาจากพาร์ทเนอร์ ลูกค้าติดต่อผ่าน KRONOCLOS ที่เดียวในทุกเรื่อง

## เปิดใช้งาน
- **โชว์ลูกค้าแบบออฟไลน์:** ดับเบิลคลิก `KRONOCLOS_Interactive_Demo.html` (ไฟล์เดียว ไม่ต้องต่อเน็ต)
- **ขึ้นโฮสต์:** อัปโหลดทั้งโฟลเดอร์ `v2/` โดยให้ `v2/index.html` เป็นหน้าแรก
- **ดูบนหลายหน้าจอ:** `devices.html` (ใช้ภายใน ไม่ต้องอัปโหลด)

## แก้ข้อมูลบนเว็บ
แก้ที่ไฟล์เดียว `v2/site-config.js` ได้แก่ อีเมล เบอร์โทร LINE ลิงก์นัดคุย ข้อมูลบริษัท กลุ่มเป้าหมาย ลิงก์แอป case study และคำตอบ FAQ ช่องไหนเว้นว่าง ส่วนนั้นจะซ่อนเอง

หลังแก้ ให้สร้างไฟล์เดียวใหม่:

```bash
python3 build_single_file.py
```

## โครงสร้าง
- `v2/index.html` หน้าเว็บ
- `v2/app.js` เนื้อหาทุกหน้า (EN/TH), เดโม และ animation
- หน้าเว็บ: หน้าแรก `#/`, โรงแรม `#/hotels`, วิธีการทำงาน `#/how-it-works`, เริ่มต้นใช้งาน `#/get-started`, คำถามและติดต่อ `#/contact`, เดโม `#demo/overview`
- `v2/site.css` สไตล์ของเว็บ (พื้นสว่าง + แถบ Graphite) และส่วนเสริมของเดโม ใช้ต่อจาก `v2/styles.css`
- `v2/data.js` ข้อมูลเดโมสมมติ
- `v2/assets/` รูปภาพ ฟอนต์ และภาพหน้าจอแอป
- `_archive_KRONOSUS/` ไฟล์ของชื่อเดิม (KRONOSUS) เก็บไว้เผื่อใช้อ้างอิง

## ก่อนเปิดเว็บจริง
- จดโดเมน kronoclos.com (ตรวจแล้วยังว่างเมื่อ 13 ต.ค. 2026) และตั้งอีเมล แล้วจึงเปลี่ยนอีเมลใน `site-config.js` ตอนนี้ยังใช้ info@kronosus.com
- ตรวจเครื่องหมายการค้าชื่อ KRONOCLOS
- ให้ทีมวิศวกรยืนยันคำตอบ FAQ และฝ่ายกฎหมายตรวจ Privacy notice
- ใส่ URL เต็มของภาพแชร์ลิงก์ (`og:image`) ใน `v2/index.html` เมื่อมีโดเมนแล้ว
- ใส่ลิงก์ App Store / Google Play เมื่อแอปพร้อม

## ขอบเขตข้อมูล
อาคาร ค่าที่อ่านได้ คำสั่ง และตัวเลขในเดโมทั้งหมดเป็นข้อมูลจำลอง ไม่มีอุปกรณ์จริงเชื่อมต่อ เครื่องคิดเลขบนหน้าแรกเป็นการประมาณจากสมมติฐานของผู้ใช้ ไม่ใช่ใบเสนอราคาหรือการรับประกันผล
